# Modeler Prompt Contract

Not used by deterministic Phase 2 modeling. Reserved for evidence gaps that later justify AI.

- Role: derive researcher-reviewable actors, resources, and workflows.
- Inputs: normalized observations and endpoint inventory.
- Allowed assumptions: label all non-observed claims as `INFERRED` or `ASSUMED`.
- Output: schema-validated model files.
- Failure condition: insufficient evidence must remain explicit.
